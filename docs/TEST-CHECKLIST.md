## APK 复核命令

```bash
AAPT2="$ANDROID_HOME/build-tools/36.0.0/aapt2"
APK="app/build/outputs/apk/debug/app-debug.apk"

"$AAPT2" dump permissions "$APK"
unzip -l "$APK"
strings "$APK" | grep -Ei 'service_role|SUPABASE_SERVICE|BEGIN (RSA |EC )?PRIVATE KEY' && exit 1 || true
sha256sum "$APK"
```

期望的应用权限只有 `INTERNET`、`SYSTEM_ALERT_WINDOW`、`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_SPECIAL_USE`、`POST_NOTIFICATIONS`、`PACKAGE_USAGE_STATS`、`VIBRATE`，以及 AndroidX 在安装包内自动加入的应用私有动态接收器签名权限。
